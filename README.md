# varungops.com

Dr Varun Gopal Rajan's personal site. Astro static build, hosted on Vercel.

- `npm run dev` for local work, `npm test` for unit tests, `npm run test:e2e` for browser tests.
- `docs/spec.md` is the design, `docs/plan.md` the build plan, `mockup/` the approved mockup it was ported from.
